# 📍 Nearby Veg & Heritage Spotter

A lightweight, mobile-first web application that helps users discover pure vegetarian restaurants and historical/heritage sites near their current location using AI.

## 🚀 Features
- **GPS Location Detection**: Uses browser geolocation to find exact latitude and longitude.
- **AI-Powered Discovery**: Queries OpenRouter API models to fetch verified local recommendations.
- **Device-Side Key Storage**: API keys are saved locally in the browser (`localStorage`), eliminating the need to re-enter credentials while keeping them secure from public repositories.
- **Mobile Optimized**: Designed specifically for smartphone screens and quick access.

## 🛠️ How to Use
1. Visit the live GitHub Pages link.
2. Enter your **OpenRouter API Key** once and tap **Save Key on This Device**.
3. Tap **Find Places Near Me** and allow location access when prompted.
4. View nearby vegetarian dining options and historic landmarks instantly.

## 🧰 Built With
- HTML5 / CSS3 / JavaScript
- GitHub Pages
- OpenRouter API
